# Getting started

You cannot learn Docker by reading about it. You need the whale on your own machine. This chapter gets you there on whichever operating system you have, and explains the one distinction that confuses nearly every beginner: Docker Desktop versus Docker Engine.

Read the first two in order. Then jump to the page for your operating system.

# Concepts

* [Installing Docker on Windows](installing-docker-on-windows.md) - Docker Desktop with the WSL 2 backend: requirements, three ways to install, first run.
* [Docker Desktop vs Docker Engine](docker-desktop-vs-docker-engine.md) - What each one is, which one you have, and when it matters.
* [Installing Docker on WSL](installing-docker-on-wsl.md) - Use Docker from inside your Ubuntu-on-Windows terminal, with Desktop or without it.
* [Installing Docker on Ubuntu](installing-docker-on-ubuntu.md) - Docker Engine from Docker's apt repository, plus the post-install steps nobody should skip.
* [Installing Docker on Mac](installing-docker-on-mac.md) - Docker Desktop on Apple silicon and Intel, by drag-and-drop, Homebrew, or the command line.
